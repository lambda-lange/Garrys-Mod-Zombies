# Garrys-Mod-Zombies

## About the project

This project was created around 2020 as a fun side project for Garry’s Mod. 
It found a small player base that enjoyed it, but since I no longer actively support it, everyone is free to use it.
The core idea is that two player-controlled teams, Survivors and Zombies, fight against each other. 
Each human and zombie has unique abilities they can use to survive or hunt down their opponents. 
Players earn XP and money through gameplay, which they can spend on new weapons or use to unlock additional playable classes.
